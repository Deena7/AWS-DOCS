scripts/start_server.sh
============================
#!/bin/bash
mkdir -p /opt/myapp
JAR_FILE=$(find /opt/myapp -name "*.jar" ! -name "*.original" | head -n 1)
nohup java -jar /opt/myapp/my-app.jar \
--server.port=8080 \
> /var/log/myapp.log 2>&1 &
echo $! > /var/run/myapp.pid
sleep 20
 
scripts/stop_server.sh 
==========================
#!/bin/bash
PID_FILE=/var/run/myapp.pid
if [ -f "$PID_FILE" ]; then
    kill -9 $(cat $PID_FILE) 2>/dev/null || true
    rm -f $PID_FILE
fi
echo "Server stopped."

scripts/validate_service.sh 
============================
#!/bin/bash
sleep 15
STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/health)
if [ "$STATUS" != "200" ]; then
    echo "Health check failed! Status: $STATUS"
    exit 1
fi
echo "Health check passed!"

Summary
===========
Action Happens Automatically
git push origin main	EventBridge detects the push to CodeCommit
EventBridge event fires	CodePipeline execution starts
SOURCE stage	Pipeline downloads your code from CodeCommit
BUILD stage	CodeBuild runs buildspec.yml → compiles code → mvn deploy to CodeArtifact
TEST stage	CodeBuild runs buildspec_test.yml → mvn test
DEPLOY stage	CodeDeploy stops old server → copies JAR → starts new server → validates
Stage fails at any point	SNS sends email to developer immediately
All stages pass	App is live! SNS sends success email


1. Always set region to ap-southeast-1 in every CLI command
2. The EventBridge rule is created automatically when you choose CloudWatch Events in CodePipeline
3. If buildspec.yml has a syntax error, CodeBuild will fail — check YAML indentation carefully
4. CodeDeploy needs the EC2 tag (App=my-app) to find the right server
5. Always confirm your SNS subscription email before testing the pipeline

Common Errors & Quick Fixes
================================
Error	                                                     Fix
Pipeline not triggered	          Check EventBridge rule is ENABLED. Go to EventBridge → Rules → verify rule exists
CodeBuild: runtime not found	  Add runtime-versions: java: corretto17 under install phase in buildspec.yml
CodeArtifact: 401 Unauthorized	  Re-run get-authorization-token command. Token expires after 12 hours
CodeDeploy: No instances found	  Check EC2 tag: Key=App, Value=my-app matches exactly what is in deployment group
CodeDeploy agent not running	  SSH into EC2 and run: sudo systemctl restart codedeploy-agent
Health check failed (validate)    Increase sleep time in validate_service.sh — Spring Boot needs 15-20 seconds to start
Email notification not received	  Go to SNS → Subscriptions → confirm status is Confirmed, not PendingConfirmation
